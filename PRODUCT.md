# Product

## Register

product

## Users

Small teams collaborating on shared Kanban boards. Members invite each other, assign tasks, and discuss work in real time. Each user manages multiple boards — some personal, some shared.

## Product Purpose

A self-hosted, real-time Kanban board for visual task management and team collaboration. Lightweight alternative to Trello/Jira — free, fast, and focused on the essential workflow: boards → columns → tasks → comments.

## Brand Personality

Modern, playful, collaborative. Approachable like Trello's early era — colorful, friendly, and unintimidating. Never dense, feature-bloated, or over-serious.

## Anti-references

Notion / Linear / Jira clones. Avoid the dark-mode-heavy, densely packed, enterprise-tool aesthetic. No gradient text, no glassmorphism, no hero-metric layouts. Keep it light, open, and inviting.

## Design Principles

1. **Approachable over powerful** — The tool should feel friendly and inviting, not like enterprise software. Trello's simplicity is the reference.
2. **Color as wayfinding** — Visual identity comes from board colors, not heavy UI chrome. Let the user's boards be the personality.
3. **Real-time by default** — Every action syncs instantly; communicate liveness without ceremony.
4. **Lightweight interactions** — Drag-and-drop, inline edit, optimistic updates. No modals where inline works.
5. **Collaboration as a feature, not an add-on** — Members, assignments, and comments are first-class, not hidden behind menus.

## Accessibility & Inclusion

WCAG AA minimum. Standard contrast ratios, keyboard navigation, and focus indicators.
